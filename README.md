# ✦ Atelier : Studio Project & Invoice Operating System

> Bespoke studio management engineered with Modern Swiss Editorial discipline, monospaced tabular numerals, and production-ready Express + EJS architecture.

### ✨ Highlights in this Initial Release:
- **Design Tokens Architecture**: Warm Obsidian (`#090A0D`), Matte Surface Glass (`#111319`), Hairline Borders, and Champagne Brass (`#D4AF37`) accents.
- **Typographic Discipline**: Triple-font system featuring **Syne** (Display), **Plus Jakarta Sans** (UI), and **Space Mono** (`tabular-nums` for jitter-free financial metrics).
- **Core Views**:
  - **Studio Matrix Dashboard**: Top KPI telemetry banner, status filter pills, and 3-column architectural cards grid.
  - **Client Dossier**: Detailed deliverables checklist with interactive milestone progress tracking.
  - **Commission Form**: Obsidian comboboxes and input fields for project initiation and updates.
  - **Minimalist Invoice Sheet**: Client-ready invoice view with dedicated `@media print` CSS for pristine PDF export without browser artifacts.
- **Power-User Ergonomics**: Keyboard shortcuts (`N` for new dossier, `/` for search, `Esc` to clear), live studio telemetry clock, and auto-generated client monogram avatars.
- **Decoupled Architecture**: Clean Service-Layer pattern isolating data operations from HTTP routes, making future PostgreSQL/Prisma database migration seamless.
